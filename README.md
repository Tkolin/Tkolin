### 🛠️ Избранные проекты

**Рекрутинг-платформа — владелец бэкенда и фуллстек** *(2024 → сейчас)*
Боевая система: ~5k пользователей, ~1k MAU, база на **50+ млн записей**.
- Спроектировал и вывел в прод микросервисы с нуля (FastAPI · Postgres · Redis · RabbitMQ) для real-time мониторинга изменений кандидатов.
- Сервис **истории резюме на diff-подходе** — хранит разницы, а не снимки, вычисления на стороне SQL → кратно меньше места.
- Помог реструктурировать серверную часть и **сократить расходы на инфраструктуру на ~40%**.
- Перестроил унаследованный фронт: 2 монолитные страницы → Feature-Sliced Design, JS → TypeScript; переписал парсер Selenium → Playwright; расширение → WXT + Vue.

**Sleep Zero — торговая платформа на Solana (full-cycle)** *(2026)*
- Сделал продукт целиком: личный кабинет (Vue 3/Nuxt), бэкенд (FastAPI), торговое ядро и расширение.
- Торговое ядро: построение транзакций для **6+ лаунчпадов**, real-time стриминг ончейн-данных через **gRPC + Yellowstone (Geyser)**, WebSocket для низкой задержки.
- **Полное покрытие бэкенда тестами** — в трейдинге ошибка = потеря денег.

**СибНИПИ — система проектной документации (соло)** *(2024–2025)*
- В одиночку, от требований до рабочей системы: PHP/Laravel + GraphQL (Apollo) + React, Postgres, Docker.
- Полный жизненный цикл документации, распределение исполнителей по диаграмме Ганта и микросервис «блюпринтов» (drag-and-drop) для вычислений внутри документов.

> Дважды вёл **два продукта параллельно** — сначала СибНИПИ + рекрутинг-платформа, затем рекрутинг-платформа + Sleep Zero.
